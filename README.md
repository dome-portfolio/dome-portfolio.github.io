# Dome Raktham · Editorial Portfolio

โปรเจกต์ HTML/CSS/JS แยกจาก Open Catalog เดิม ใช้โครงและเนื้อหาจาก HTML/CSS ที่แนบ พร้อมภาพ ฟอนต์ หน้าโครงการ และตัวเล่นจากพอร์ตเดิม

## เปิดใช้งาน

แตก ZIP แล้วเปิด index.html ในเบราว์เซอร์ เก็บโฟลเดอร์ assets/ และ projects/ ไว้ข้างกัน เว็บและไฟล์ Motion ในชุดเปิดได้จากเครื่อง ส่วน TikTok, Facebook, LINE และเว็บไซต์ภายนอกต้องเชื่อมต่ออินเทอร์เน็ต

สำหรับนำขึ้น static hosting ให้อัปโหลดโฟลเดอร์นี้โดยไม่ต้อง build ตั้งค่า URL ของ og:image และ twitter:image เป็น URL เต็มบนโดเมนจริงก่อนแชร์

## แก้ไข

- index.html และ en/index.html เก็บเนื้อหาหน้าแรกภาษาไทยและอังกฤษ
- styles.css เก็บฟอนต์ สี ระยะห่าง กริด และรูปแบบร่วมของหน้าโครงการ
- projects/ และ en/projects/ เก็บหน้าผลงานภาษาไทยและอังกฤษ เพิ่มโปรเจกต์เป็นคู่และเชื่อมปุ่มสลับภาษาให้ชี้ไปยังหน้าเดียวกันในอีกภาษา จากนั้นอัปเดตรายการผลงานและลำดับปุ่มถัดไปทั้งสองชุด ตัวอย่าง HTML อยู่ใน templates/ และ en/templates/
- script.js ดูแลโฟกัสและสถานะของลิงก์ในเมนู ส่วน media-player.js ดูแลตัวเล่น
- gallery.js จัดกริด Masonry และเปิดตัวดูภาพใหญ่ ลิงก์ `data-image` ในกริดชี้ไปยังไฟล์เต็มใน assets/artwork/full/ ส่วนภาพย่ออยู่ใน assets/artwork/preview/ ใช้ `data-gallery-scope` กับหน้าผลงานที่ต้องการให้ปุ่มลูกศรเลื่อนข้ามชุดภาพในหน้าเดียวกัน
- assets/line-qr.png สร้างจาก LINE URL เดียวกับปุ่มติดต่อ
- แก้เบอร์โทรและอีเมลในลิงก์ `tel:` และ `mailto:` ในหน้าแรกทั้งสองภาษา

## ตรวจแล้ว

เปิดหน้าแรกและหน้าผลงาน 11 หน้าในแต่ละภาษา ที่ 320, 390, 768 และ 1440 px ตรวจกริด ลิงก์ และภาพครบ 175 รูปต่อภาษา พร้อมทดสอบการเปิดภาพใหญ่ การเลื่อนด้วยลูกศร และการเล่นไฟล์ Motion
